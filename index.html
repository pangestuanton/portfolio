AVIONA SYNC — SYSTEM CASE STUDY

Laravel-based Automated Academic Assistant

PROJECT OVERVIEW

Aviona Sync is a real-world, production-ready platform designed for university students to unify their academic lives. It automatically polls and centralizes Google Classroom tasks, class schedules, and grades, syncs them to Google Calendar, and broadcasts daily agendas and push alerts via a Telegram Bot.

Launch Application

INTEGRATION PIPELINE

  • Google OAuth 2.0: Manages secure user authentication, token storage, and background token refresh processes.
  • Google Classroom API: Queries courses, active courseworks, announcements, and materials to detect new deadlines.
  • Google Calendar API: Programmatically maps coursework deadlines to a dedicated secondary calendar in the user's Google Calendar.
  • Telegram Bot API: Dispatches automated daily summaries (every morning at 07:00 AM) and urgent reminders (24 hours before deadlines).
